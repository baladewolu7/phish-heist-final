# Phish Heist

Phish Heist is an interactive cybersecurity awareness game created for RowdyHacks 2026.

## About

Cybercriminals often use phishing messages to steal passwords, financial information, and other sensitive data.

Phish Heist turns phishing awareness into a heist-themed game. Players act as cybersecurity agents protecting a digital vault by deciding whether incoming messages are legitimate or phishing attempts.

## How to Play

1. Click **Start the Mission**
2. Review the sender, subject, message, and link
3. Choose **Phishing** or **Legitimate**
4. Learn why the message was safe or suspicious
5. Protect the vault through all six messages

## Features

- Six phishing-awareness scenarios
- Immediate cybersecurity explanations
- Score tracking
- Vault health system
- Correct and incorrect feedback
- Final success or breach result
